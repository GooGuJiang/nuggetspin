# Nuggetspin

## Introduction

Welcome to Nuggetspin, my very first web development project. Inspired by the YouTube video ["Nugget SPEENS for 4 Minutes"](https://www.youtube.com/watch?v=3HtnwSlgb6U), this website is a fun, simple demonstration of a chicken nugget spinning.

## What to Expect

When you visit the site, you will be greeted with a single, captivating sight: a chicken nugget in perpetual motion. Accompanying the spinning nugget is an endlessly looping piece of music to enhance the viewing experience. It's a straightforward, playful experiment in web development that I hope you'll enjoy.

## Project Status

This project is currently in its initial stages. As my first foray into web development, the code might seem a bit messy and the aesthetics of the page might not be up to par. However, this project represents an important learning journey for me, and I am excited to see how it evolves and improves over time.

## Dev Instructions

To set up the project locally, follow these steps:

1. Clone the repository to your local machine.
2. Run `pnpm install` to install all necessary dependencies.
3. Run `pnpm dev` to start the local development server.

Please make sure you have pnpm installed on your machine before running these commands.
